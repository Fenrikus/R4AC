# 06. Правові вимоги та комплаєнс

> Це інженерне резюме для планування, **не юридичний висновок**. Перед запуском —
> погодження з юристом компанії; для парку з обробкою даних працівників це обов'язковий крок.

## 1. Чому це блок №1, а не додаток

Відеозйомка працівника на робочому місці — це **обробка персональних даних**. Некоректно
оформлена система дає три ризики одночасно:
1. **Докази стають непридатними** — запис, отриманий з порушенням, суд може не врахувати.
2. **Відповідальність компанії** — за ЗУ «Про захист персональних даних», за КЗпП.
3. **Кримінальний ризик** за приховане (негласне) спостереження технічними засобами.

Тобто система, зроблена «тихо», не виконує головної функції — доказовості.

## 2. Українська рамка

| Джерело | Що вимагає |
|---------|-----------|
| Конституція України, ст. 32 | заборона збирання, зберігання, використання й поширення конфіденційної інформації про особу без її згоди |
| ЗУ «Про захист персональних даних» № 2297-VI | законна підстава обробки, визначена мета, інформування суб'єкта, захист даних, права суб'єкта |
| КЗпП України (зокрема ст. 29) | інформування працівника про умови праці під підпис, ознайомлення з правилами внутрішнього трудового розпорядку |
| ЗУ «Про інформацію» | режим конфіденційної інформації про особу |
| КК України | відповідальність за незаконне використання спеціальних технічних засобів негласного отримання інформації |
| Законопроєкт № 8153 (прийнятий у 1-му читанні 20.11.2024, готується до 2-го) | нова редакція закону про персональні дані, наближення до GDPR: обов'язкове інформування, DPO, повідомлення про інциденти, суттєві штрафи |

**Практичний висновок:** проєктувати систему одразу за логікою GDPR — дешевше, ніж
переробляти після ухвалення № 8153.

## 3. Європейська рамка (орієнтир на майбутнє й для роботи з ЄС)

- **EDPB Guidelines 3/2019** щодо обробки персональних даних через відеопристрої
  (ухвалені 29.01.2020): законність, прозорість, розкриття третім особам, спеціальні категорії даних.
- **Лист EDPB від 05.05.2025** про камери в автомобілях і відеореєстратори: оператор має
  оцінити свою роль, ризики й забезпечити прозорість та права суб'єктів даних.
- Ключове для нас: для моніторингу працівників **згода зазвичай не є надійною підставою**
  (немає свободи волі в трудових відносинах). Робоча підстава — **законний інтерес роботодавця**
  плюс тест на пропорційність (LIA) і мінімізація даних.

## 4. Комплект документів — must have до першого ввімкнення камери

| # | Документ | Зміст |
|---|----------|-------|
| 1 | **Наказ** про впровадження системи відеоспостереження у службовому транспорті | мета, перелік авто, відповідальні, дата запуску |
| 2 | **Положення про відеоспостереження** | що знімається, де, коли, хто має доступ, строки зберігання, порядок надання доступу |
| 3 | Зміни до **Правил внутрішнього трудового розпорядку** | фіксація факту моніторингу як умови праці |
| 4 | Зміни до **посадових інструкцій / трудових договорів** | обов'язок працівника не перешкоджати роботі системи |
| 5 | **Повідомлення працівника під підпис** (КЗпП) + окрема письмова згода там, де вона доречна | прозорість, доказ інформування |
| 6 | **Політика захисту персональних даних** + інструкція для персоналу, що обслуговує систему | вимога ЗУ 2297-VI |
| 7 | **Оцінка законного інтересу (LIA)** та за потреби **DPIA** | пропорційність: чи не можна досягти мети менш інвазивним способом |
| 8 | **Журнал доступу до відеоархіву** | хто, коли, що дивився, з якої підстави (FR-31) |
| 9 | **Регламент реагування на інциденти й запити суб'єктів даних (DSAR)** | строки, форма відповіді |
| 10 | **Договір з підрядником/вендором (DPA)** | вендор як розпорядник даних, заборона вторинного використання |
| 11 | **Інформаційні наклейки** в салоні та на склі | «Ведеться відеоспостереження», контакти відповідального |

## 5. Правила проєктування, що знижують ризик

| Принцип | Реалізація в системі |
|---------|----------------------|
| Мінімізація | немає аудіо; салонна камера — подієво; ретенція 30–90 діб, не «назавжди» |
| Обмеження метою | запис лише в робочий час і при увімкненому запалюванні (FR-07) |
| Прозорість | наклейки, ознайомлення під підпис, доступ водія до власного рейтингу |
| Пропорційність | немає прихованих камер, немає розпізнавання облич, немає контролю поза зміною |
| Підзвітність | незмінний журнал переглядів, квартальний звіт DPO |
| Захист | шифрування, RBAC, mTLS, обмежене коло осіб з доступом |
| Права суб'єкта | процедура DSAR-експорту (FR-35), порядок оскарження оцінки водієм |

## 6. Окремі чутливі питання

- **Салонна камера на водія.** Найбільш інвазивний елемент. Позиція, яку легко захистити:
  запис на борт, у хмару — лише кліпи по подіях безпеки (втома, телефон, ремінь, удар),
  доступ — за окремою підставою. Тотальний онлайн-перегляд салону «щоб подивитись, що він робить» —
  саме те, що робить систему вразливою і юридично, і з погляду персоналу.
- **Пасажири в мікроавтобусі.** Це вже треті особи — обов'язкові наклейки в салоні
  та мінімізація зберігання.
- **Особисте використання авто** (якщо дозволене) — окремий режим: у неробочий час
  салонна камера вимкнена, телеметрія обмежена.
- **Транскордонна передача.** Якщо платформа хостингується поза Україною/ЄС — потрібні
  договірні гарантії; враховувати при виборі сценарію A (`04-rynok.md`).
- **Профспілка / представники трудового колективу** — доцільно залучити до узгодження
  Положення: це знімає більшу частину майбутніх конфліктів.
