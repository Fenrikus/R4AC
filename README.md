# Система відеоспостереження у службових автомобілях

Аналітичні та проєктні матеріали до впровадження системи відеофіксації дій персоналу
в робочий час для парку службових авто (седан, SUV, мікроавтобус).

**Статус:** аналіз і базова архітектура, v0.1 — для обговорення та ухвалення рішення
щодо пілоту. Цінові цифри — оціночні орієнтири, підлягають підтвердженню КП.

## Калькулятор TCO

```bash
python3 tools/tco.py                          # базовий сценарій: 30 авто, 3 роки
python3 tools/tco.py --sedan 20 --suv 40 --van 40 --years 5
python3 tools/tco.py --breakeven              # точка беззбитковості self-hosted
```

## Стислі висновки

1. **Edge-first архітектура** (відео живе на борту, у хмару йдуть події) — головний важіль
   вартості: різниця з постійною трансляцією десятикратна за трафіком.
2. На парку до ~85–100 авто економічно виграє **готове рішення від українського інтегратора**
   (~1 200 ₴/авто/міс. на горизонті 3 років); власна платформа окуповується від ~100 авто.
3. **Правовий пакет — блокуючий елемент, не додаток**: без наказу, положення, ознайомлення
   під підпис і журналу доступу записи втрачають доказову силу.
4. Салонна камера — подієво, без аудіо, без запису поза робочим часом: це одночасно
   і комплаєнс, і економія, і зниження опору персоналу.
5. **Максимум функцій ≠ потрібний функціонал.** З 14 функціональних доменів найвищий рівень
   потрібен лише у трьох — і у двох із них (контроль виконання роботи, приватність та аудит)
   ринок не дотягує. Саме туди йде власна розробка (~1,5–2 людино-місяці поверх готової
   платформи), а не в дублювання AI-аналітики, яку вендори роблять краще.
